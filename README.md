# test-bot

Тестовый Telegram-бот с воронкой в закрытый канал по ежемесячной подписке.

## Сценарий

1. Бот приветствует пользователя.
2. Показывает, что находится внутри канала.
3. Объясняет ценность закрытого формата.
4. Показывает оффер.
5. Выдаёт нативную платную ссылку Telegram.
6. После оплаты Telegram автоматически добавляет пользователя в приватный канал.

## Что реализовано

- пошаговая воронка на inline-кнопках;
- ежемесячная подписка через Telegram Stars;
- кэширование платной ссылки в SQLite;
- проверка канала и прав бота при старте;
- аналитика переходов по этапам;
- команды администратора `/stats` и `/refresh_link`;
- `/paysupport` для вопросов по оплате.

## Настройка

1. Создай приватный Telegram-канал.
2. Добавь бота администратором с правом приглашать пользователей.
3. Скопируй `.env.example` в `.env`.
4. Заполни токен, ID канала, цену и ID администраторов.

```bash
cp .env.example .env
```

Основные параметры:

```dotenv
BOT_TOKEN=123456:token
ADMIN_IDS=123456789
PRIVATE_CHANNEL_ID=-1001234567890
SUBSCRIPTION_PRICE_STARS=150
SUPPORT_USERNAME=your_support
```

## Запуск

Требуется Python 3.12+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
python -m bot
```

На Windows активация окружения:

```powershell
.venv\Scripts\Activate.ps1
```

## Команды

- `/start` — начать воронку заново;
- `/help` — помощь;
- `/paysupport` — контакт поддержки;
- `/stats` — статистика воронки, только для `ADMIN_IDS`;
- `/refresh_link` — принудительно создать новую платную ссылку.

## Где менять тексты

Пользовательские сообщения и порядок этапов находятся в `bot/handlers.py`. Для реального проекта их лучше вынести в отдельный модуль после согласования финального контента.
