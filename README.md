# test-bot

Тестовый Telegram-бот с простой воронкой в закрытый канал по ежемесячной подписке.

## Что уже есть

- цепочка сообщений: приветствие → содержимое → объяснение → оффер;
- нативная ежемесячная подписка Telegram Stars;
- автоматическое добавление пользователя в приватный канал после оплаты;
- автоматическое продление каждые 30 дней средствами Telegram;
- SQLite-аналитика прохождения воронки;
- команды администратора `/stats` и `/refresh_link`;
- Docker-конфигурация для запуска на сервере.

## Почему используется платная ссылка канала

Для доступа к цифровому контенту внутри Telegram применяется Telegram Stars. Бот создаёт `createChatSubscriptionInviteLink`, а Telegram сам:

1. показывает пользователю окно оплаты;
2. добавляет его в закрытый канал после успешной оплаты;
3. продлевает подписку раз в 30 дней;
4. управляет сроком доступа при отмене или нехватке Stars.

Это проще и надёжнее самописной схемы с инвойсом, временной ссылкой и отдельным удалением просроченных пользователей.

## Настройка

1. Создай бота через `@BotFather`.
2. Создай приватный **канал**.
3. Добавь бота администратором канала и выдай право приглашать пользователей.
4. Скопируй `.env.example` в `.env`.
5. Заполни `BOT_TOKEN`, `CHANNEL_ID`, цену и ID администратора.

Чтобы узнать numeric ID канала, можно переслать сообщение из него боту, который показывает ID, либо получить ID через Bot API.

## Запуск через Docker

```bash
cp .env.example .env
# отредактировать .env
docker compose up -d --build
```

Логи:

```bash
docker compose logs -f bot
```

## Локальный запуск

Требуется Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
set -a && source .env && set +a
python -m app.main
```

## Где менять тексты

Все сообщения находятся в `app/content.py`. Кнопки и порядок шагов — в `app/keyboards.py` и обработчиках `app/main.py`.

## Команды

- `/start` — начать воронку заново;
- `/help` — помощь;
- `/paysupport` — контакт поддержки;
- `/stats` — статистика воронки, только для `ADMIN_IDS`;
- `/refresh_link` — создать новую платную ссылку, только для `ADMIN_IDS`.

## Важные ограничения Telegram

- платная подписка через такую ссылку работает только для канала;
- период сейчас фиксированный: 30 дней;
- цена — от 1 до 10000 Telegram Stars;
- бот должен быть администратором с правом приглашать пользователей.
